# Stockfish runtime

`tools/install-stockfish.sh` installs the official Stockfish sf_19 universal Linux binary for x86-64, ARM64, or
RISC-V here. The binary and its `Copying.txt` license are generated install artifacts and are not source files.
The installer verifies the official release archive's SHA-256 digest before extraction.

Stockfish is distributed under GPL-3.0. See `Copying.txt` after installation and the official source at
https://github.com/official-stockfish/Stockfish.
